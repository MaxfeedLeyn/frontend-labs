# Лабораторна робота №13–15

## **Мета: Авторизація**

1. Перенести попередню лабораторну.

2. **Створити інтерфейс авторизації**, який містить:

   * кнопку **“Увійти”**,
   * кнопку **“Реєстрація”**,
   * *після успішного входу ці дві кнопки мають зникнути*,
   * і замість них має з’явитися кнопка **“Вийти”**.

3. **Реалізувати перевірку логіна та пароля**

   * використати “мок”-користувачів або API (GAS);
   * реалізувати стан авторизації;
   * реалізувати вихід (**logout**) із поверненням початкового інтерфейсу.

4. **Обмежити доступ і функціонал у застосунку:**

   * захищені маршрути (доступні лише після авторизації);
   * елементи інтерфейсу, що потребують входу, мають бути **неактивні або приховані** до авторизації;
   * (за бажанням) різний рівень доступності кнопок залежно від ролі.

5. Стилізувати інтерфейс та кнопки за допомогою **Tailwind + daisyUI** (використати вже встановлені бібліотеки).

6. Опублікувати застосунок на **Netlify**.

7. Завантажити виконану роботу в **GitHub Classroom**.

8. Оформити звіт і додати посилання у **Google Classroom**.
